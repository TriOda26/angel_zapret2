# zapret2

Плагин angelOS для локального **zapret2**: пиксельное яблоко на панели, пульт, профили доменов, журнал, стратегии и необязательный polkit helper.

![preview](preview.png)

## Что он делает

- Показывает состояние `zapret2.service` в баре пиксельным яблоком.
- Ангелочек и Демон комментируют включение, смену профиля, ошибки и починку сервиса (реплики можно выключить в настройках); говорят только они, системные файлы AngelOS не трогаются.
- ЛКМ открывает компактный пульт, ПКМ по умолчанию включает/выключает обход. Поведение ЛКМ можно поменять в настройках плагина.
- Если сервис не найден, пульт показывает карточку «Сервис zapret2 не найден» с настройкой папки и инструкцией по установке.
- Переключает ваши профили из `~/.config/zapret2/profiles/` — вы создаёте их сами (в настройках плагина или в папке).
- Позволяет править активный список доменов и в пульте, и в настройках, и внешним
  редактором.
- Показывает `journalctl` сервиса, текущие стратегии из `NFQWS2_OPT` и запускает
  `blockcheck2.sh`.
- Добавляет пункты в ПКМ-меню рабочего стола и результаты в лаунчер (`zap`).

## Зависимости

- angelOS с поддержкой user plugins;
- установленный zapret2 (пакет `zapret2`, исходник `github.com/bol-van/zapret2`), по умолчанию
  в `/opt/zapret2`;
- systemd-юнит `zapret2.service`;
- для запуска/остановки без пароля — polkit-агент и helper (ставится из настроек);
- `journalctl`, `pgrep`, `notify-send` (обычно уже есть).

Плагин не скачивает и не запускает код из сети. Все действия — локальные команды
`systemctl`, `journalctl`, `cat`, `readlink`, `nano`.

## Установка

```bash
mkdir -p ~/.config/angelos/plugins
cd /path/to/angel_zapret2
cp -a . ~/.config/angelos/plugins/zapret2
```

Затем включите **Настройки → Плагины → zapret2**. Плагин выключен по умолчанию.

## Первый запуск

1. Поставьте zapret2 и включите юнит:
   ```bash
   sudo pacman -S zapret2
   sudo systemctl enable --now zapret2.service
   ```
   Если пакета нет в репозитории, соберите его из `https://github.com/bol-van/zapret2`.
2. Если zapret2 лежит не в `/opt/zapret2`, откройте **Настройки → Сервис → Папка → Выбрать…**
   и укажите папку; имя юнита можно проверить там же. При первом включении без сервиса плагин один раз показывает окно «Сервис zapret2 не найден».
3. Откройте настройки плагина и нажмите **Исправить** рядом со «Связь hostlist» либо
   **Установить** рядом с `polkit helper`. Появится запрос пароля.
4. Helper создаст симлинк
   `/opt/zapret2/ipset/zapret-hosts-user.txt → ~/.config/zapret2/active.txt`
   и правило `/etc/polkit-1/rules.d/49-zapret2.rules`, разрешающее этому пользователю управлять только `zapret2.service`.
5. После этого кнопки в пульте работают без пароля.

Если helper не нужен, всё равно можно пользоваться плагином: `systemctl` будет
спрашивать пароль через polkit, а профили требуют symlink (его можно создать вручную).

## Файлы

| путь | что |
|---|---|
| `/opt/zapret2/config` | конфиг zapret2, `NFQWS2_OPT` (папка настраивается) |
| `/opt/zapret2/ipset/zapret-hosts-user.txt` | hostlist (симлинк на активный список) |
| `~/.config/zapret2/active.txt` | текущий список доменов |
| `~/.config/zapret2/profiles/*.txt` | профили |
| `/etc/polkit-1/rules.d/49-zapret2.rules` | правило helper-а для выбранного юнита |
| `/usr/lib/systemd/system/zapret2.service` | юнит (путь берётся из `systemctl show`) |

## Управление

| где | действие |
|---|---|
| бар, ЛКМ | пульт |
| бар, ПКМ | включить/выключить обход |
| бар, СКМ | обновить состояние |
| пульт | старт/стоп, профиль, Журнал, Домены, «Ещё» (Рестарт/Стратегии/Конфиг/Настройки) |
| лаунчер | `zap` → действия и профили |
| ПКМ по рабочему столу | пункты zapret2 |

## Настройки

- подпись профиля рядом с яблоком;
- поведение ЛКМ (пульт или переключение);
- уведомления;
- голоса Ангелочка и Демона;
- активный профиль и сохранение текущего списка как нового профиля;
- редактор доменов;
- просмотр стратегий, запуск blockcheck;
- папка и юнит сервиса (с автопоиском и выбором папки), автозапуск и перезапуск;
- установка/удаление polkit helper;
- диагностика в JSON и копирование в буфер.

## Безопасность

- Helper запускается только через `pkexec` и только по нажатию кнопки.
- Polkit-правило разрешает управлять **только** выбранным юнитом (`zapret2.service` по
  умолчанию) и включать/выключать только его автозапуск.
- `openConfig()` и `blockcheck()` запускают `sudo` в терминале: это явные действия
  пользователя, а не фоновая запись в `/opt`.
- Плагин не хранит пароли и не пишет в системные файлы без helper-а. Настройки плагина лежат в `~/.config/angelos/settings.json`.

## Удаление

```bash
rm -rf ~/.config/angelos/plugins/zapret2
```

Правило helper-а можно удалить в настройках плагина кнопкой **Удалить** (symlink при
этом остаётся, чтобы профили продолжали работать).

## Разработка

- локальная разработка, формат ZIP и публикация в Community Registry — в `CONTRIBUTING.md` в репозитории проекта;
- `bash tools/package-release.sh` (в репозитории) собирает
  `${ZAPRET2_RELEASE_DIR:-/tmp/zapret2-release}/angel_zapret2-<version>.zip`, проверяет архив и
  печатает SHA-256; сам ZIP в репозиторий не попадает;
- изменения по версиям — в [CHANGELOG.md](CHANGELOG.md).
